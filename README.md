# Pet Name Generator

GitHub Pages ready, flat-root static website. Upload every file in this ZIP to the repository root.

## Expected live URL
https://mirzacreative.github.io/petnamegenerator/

## Deployment
1. Create or open the `petnamegenerator` GitHub repository.
2. Upload the extracted files to the repository root.
3. In Settings > Pages, deploy from the main branch and root folder.
4. After deployment, submit `https://mirzacreative.github.io/petnamegenerator/sitemap.xml` in Google Search Console.
5. Request indexing for the homepage and primary generator pages.

## Important
Search ranking is not guaranteed. Technical optimization helps crawling and understanding, while ranking also depends on content quality, competition, links, domain history and user signals.
